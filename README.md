# FLEET CHARIOT 1.3.9

La barre d’état est masquée : l’application utilise également la zone supérieure de l’écran, dès son lancement. Les notifications restent accessibles par un glissement depuis le haut. Le réglage est réappliqué au retour dans l’application et après la fermeture du clavier ; les zones de sécurité des contrôles sont conservées.

Les parcours de la 1.3.8 restent en place : fenêtre jaune de main-d’œuvre interne/externe, signalement du conducteur, commande externe ou annulation, transport sans début/fin, horaires de main-d’œuvre indicatifs, formules Éco/Classic/Premium uniquement pour le personnel.

APK ARM64, même identifiant et même signature que la distribution précédente. Backend inchangé : https://tout-chariot-staging.fly.dev. La clé de signature historique reste à fournir pour les installations utilisant l’ancien certificat. PI-SPI reste sur le simulateur TGD999 ; les accès bancaires de production et le fournisseur SMS restent à raccorder. Les numéros autorisés utilisent actuellement 1234.

La livraison publique contient l’APK et ses documents, sans code source.
